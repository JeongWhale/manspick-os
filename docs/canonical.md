## 패키지

## 플로우
카톡 문의 → 직원이 OS 링크 복붙 → 고객 옵션 선택 + 기본정보 (여기서 고객 생성) → OS 내부 설문 → 시스템 자동 배정·즉시 확정 → 배정 디렉터 슬롯에서 고객이 날짜 선택 → 확정 안내 7종 → 리마인드 → 촬영 당일 체크리스트 → 셀렉(디렉터 선별 후보만) → 보정 → 전달(1~3일) → 후속.

## 자동 배정 우선순위
난이도 → 가능 일정 → 업무량 균등 → 지역. 로직은 고객에게 비노출.

## 셀렉
주체는 설문에서 고객이 선택, 현장에서 변경 가능, 촬영 종료 시 확정.

## 확정 안내 7종
촬영일 확정 / 준비물 / 의상 / 부가서비스 / 커리큘럼 / 장소 / 변경·취소 규정

## 리마인드 4요소
기대감 / 장소·시간 / 전날 금지사항 / 환대 멘트

## 당일 플로우

## 운영·기술 확정 (2026-09-29)
- 월 60건+ / 디렉터 3 / 보정가 2(내부) / 대표 1. 4역할 동시 출시.
- 성공 기준(4주): 신규 고객 전원이 OS 안에서 7단계 완주.
- 스택: Next.js + Supabase + Vercel. 고객 인증: 링크 + 전화번호 뒤 4자리.
- 설문 사진: Storage 업로드(유일 예외). 그 외 파일은 링크.
- 결제: PG 없음. 경로 다양(크몽·프립·숨고·스마트스토어·계좌이체, 보통 선불 전액). 선결제 고객도 OS에서 옵션 재선택 + 기본정보에 결제 경로·금액 입력. 직원이 일정 확정 전 확인(상태 `결제 확인 대기`, 슬롯 24시간 임시 잠금). 기존 고객 이관 없음. 사이트 연동 없음.
- 상태 전이: 순서대로만. 건너뛰기·되돌리기는 admin/staff + 사유 필수.
- 보정가 배정: 촬영일 요일 규칙 — 월·화 신민정 / 수~일 최경선. 대표 변경 가능(사유). 규칙은 설정에서 수정 가능.
- 변경·취소·환불: 규정 안내만, 처리는 수동.
- 후기 → 원본: 직원 수동 확인·전달.
- 후속 이벤트: 후기→원본, 추가 보정, 재방문/지인소개 5천원, 블로그. 운영자가 추가/수정 가능해야 함.
